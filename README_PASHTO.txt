زدکړیال — Master System v1

دا فولډر د زدکړیال د Master System شرایط، معماري او موجود Backend بنسټ ساتي.
ټول اساسي شرایط باید د راتلونکو کوډینګ او Database کارونو پر مهال وساتل شي.

اصلي جوړښت:
University → Faculty → Department → Semester → Subject → Course → Module → Lesson

مهم قواعد:
- محصل تر تایید مخکې بشپړ تعلیمي لاسرسی نه لري.
- Current او Lower Semester اجازه لري؛ Higher Semester بند دی.
- د خپل رشته/پوهنځي محتوا اصلي لاسرسی دی.
- د نورو پوهنځیو ویډیو لیدل کېدای شي، خو Protected Download باید بند وي.
- Paid content یوازې د تایید شوي Purchase/Access وروسته بشپړ خلاصیږي.
- Protected premium video باید د عادي MP4 فایل په ډول ښکاره نه شي؛ قوي Offline/DRM لپاره Native App + Encryption + Widevine/FairPlay ته اړتیا ده.
- One Account → One Device د امنیتي بنسټ برخه ده.
- Semester count باید د هر Faculty/Department لپاره Dynamic وي.

سیستم کې باید شامل وي:
QBank, Smart QBank, Adaptive Learning, Study Plans, Flashcards, Clinical Cases,
AI Tutor, Library, Live Classes, Teacher Verification, Local Payment, Teacher Earnings,
Progress Dashboard, Achievements, Certificates/QR, Search, Admin Panel, Analytics,
Notifications, Discussion, Pashto/Dari/English او قوي Security.

موجود Backend: zdakrhyal_server_backend.js
یادونه: دا Backend د امنیت بنسټ دی، خو True DRM/Native Offline DRM لا بشپړ نه دی.
