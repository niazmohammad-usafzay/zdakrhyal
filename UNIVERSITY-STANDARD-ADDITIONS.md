# د پوهنتون لپاره اضافي معیاري شرایط

دا موارد د Master Requirements تر څنګ د Professional University Foundation په توګه ثبت شوي:

1. University / Campus / Faculty / Department / Program جلا مدیریت.
2. Degree level: Bachelor, Master, Doctorate او Diploma.
3. Academic Year، Semester/Term او Academic Calendar.
4. Credit Hours، Contact Hours، Core/Elective subjects.
5. Course Code، Course Outcomes او Prerequisites.
6. Enrollment/Registration او د مضمون انتخاب workflow.
7. Attendance، Excused Absence او attendance percentage.
8. Assessment/Exam، Grade، Grade Point او GPA.
9. Transcript، Academic Standing او د فراغت شرایط.
10. Academic integrity، plagiarism/cheating policy او disciplinary workflow.
11. Student appeals/grievance او support ticket workflow.
12. Teacher qualification، document verification او content moderation.
13. Accessibility، RTL/LTR، multilingual content او mobile responsive UX.
14. Privacy، consent، data retention او audit logs.
15. Role-based access: Student, Teacher, Advisor/Reviewer, Admin, Super Admin.
16. Server-side academic authorization؛ frontend یوازې د امنیت وسیله نه ده.
17. Secure payments، receipt review، refunds او financial audit trail.
18. Backup/restore، disaster recovery، monitoring او production health checks.
19. API versioning، validation، rate limiting، error handling او logging.
20. د Production لپاره PostgreSQL/Supabase، private storage، CDN، HTTPS او protected video/DRM باید د migration phases کې بشپړ شي.

یادونه: د هر پوهنتون رسمي grading scale، credit policy، attendance threshold او graduation rules باید د هماغه پوهنتون د رسمي مقرراتو له مخې تنظیم شي؛ په کوډ کې باید د یوې ادارې قواعد په زور ثابت نه شي.
